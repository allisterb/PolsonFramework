# Logo Designer (AGY Single-Agent Harness)

Autonomous logo designer harness leveraging Polson's `Logo` and `Skia` tools.

## Directives
- Construct precision geometric vectors.
- Validate multi-scale legibility across 16px–256px favicons.
- Save intermediate studies to `artifacts/` using `ExecuteScript(..., outFile="artifacts/...")`.
- Output final presentation board to `output.webp` and save full JavaScript to `artwork.js`.
