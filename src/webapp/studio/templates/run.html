how this is coded

Every action is coded by what it does for the work — not by whether it was any good. Positive is the agent regulating how it engages: saying what it is doing, fetching material, looking at what is there. Negative is production, the moment the artifact actually changes. The curve is the running total, so it climbs through preparation and falls as work lands.

Neither direction is better. A run that only climbs never made a mark; one that only falls never checked anything. What the shape is for is seeing how a collaboration moved over time — and, once two agents share an axis, whether their turning points track each other, which is where participatory sense-making becomes visible rather than argued.

The categories are Nicholas Davis's; the values are his 2025 table, re-derived for a medium of scripts and renders. docs/creative-sense-making.md carries the derivation and says which row is ours rather than his.
