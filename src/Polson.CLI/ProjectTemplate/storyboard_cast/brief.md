## The cast

**One row per character.** Each is built once from a turnaround and then posed in every panel, so
what matters here is what the body and clothes look like from every side — not a list of
expressions, which are set per panel.

| Character | Described as — build, age, clothes, hair | Must stay the same in every panel | Panels they appear in | Built or minor |

| | | | | |
| | | | | |

**Must stay the same** is the short list a reader would notice changing: a mark and which side it is
on, something worn only in some panels, and **which hand holds a prop** — a lantern that changes hands
between panels is a continuity error even when every panel is right on its own. Write it down now; it
is what each panel is checked against.

> **Three is a lot, so decide who is built.** Each built character takes minutes and the builds queue.
> Build the people the story follows across panels. A **minor** character — in one panel, or only ever
> small or seen from one side — is one front-view cutout with no build. A **background type** — a crowd,
> a patrol — is one representative cutout reused for everyone of that type. Ask the director if the
> brief does not make it clear which is which.

> **A named real person is not available as a generated face.** If the brief wants a specific actor or
> a real individual, say so here.
