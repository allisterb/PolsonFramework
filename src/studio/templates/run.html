how this is coded

Every action is coded by what it does for the work — not by whether it was any good. Positive is the agent regulating how it engages: saying what it is doing, fetching material, looking at what is there. Negative is production, the moment the artifact actually changes. The curve is the running total, so it climbs through preparation and falls as work lands.

Neither direction is better. A run that only climbs never made a mark; one that only falls never checked anything. What the shape is for is seeing how a collaboration moved over time — and, once two agents share an axis, whether their turning points track each other, which is where participatory sense-making becomes visible rather than argued.

The categories are Nicholas Davis's; the values are his 2025 table, re-derived for a medium of scripts and renders. docs/creative-sense-making.md carries the derivation and says which row is ours rather than his.

what these mean
stage
the agent declaring which phase of the work it has entered
note
its own account of what it is doing and why — written for you, not for itself
executing / executed
a script sent to the drawing engine, and its return
failed
a script the engine refused; the message says why
rendered
an image was written. Click any line with a to see it
looked
the script measured, sampled or compared something before drawing
read back
this pass opened an artifact an earlier pass made — the record of one pass building on another
thinking
the model's own reasoning. Folded to a line; click to open
said
the agent speaking to you. Clipped to five lines; click to open
provider
the model's own hosting failing, not the agent — a rate limit or an outage. Retryable ones are retried and the run carries on
tool
a call to something outside the drawing engine — a file read, a search
asking / answered
a question put to you, and how it was settled
director
you, speaking into the run
gap
events the stream could not keep, said plainly rather than passed over

A run whose documents sit on disk and are unreachable from the page has done the work and not delivered it. Hidden until there is one.
