# Claude MCP Server Test Harness

This directory is an autonomous agent testing harness for the Polson Model Context Protocol (MCP) server.

## Purpose
Allows an autonomous Claude Code agent to interact with the Polson MCP server using only public MCP resources (`polson://sdk/*`) and tools (`ExecuteScript`, `RenderSvg`, `MeasureSvgPath`, `History`) to generate artwork and report developer experience findings.

## Files
- `CLAUDE.md`: Primary instructions for Claude Code, including the creative prompt and ground rules.
- `.mcp.json`: MCP server configuration pointing to `Polson.CLI`.
- `findings.md`: Structured evaluation template.
- `artwork.js`: Resulting script output generated by the agent.

## Launching
To run a test session with Claude Code:
```bash
cd tests/agent/mcp-server/claude
claude
```
