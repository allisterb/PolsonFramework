# Polson Logo Design Studio (AGY Multi-Agent Harness)

Multi-agent collaborative logo design environment orchestrating geometric mark construction and brand presentation board synthesis.

## Available Agents
- `geometer`: Precision Mark Architect (Golden circles, logarithmic spirals, tangent blends, squircle containers).
- `stylist`: Brand Designer (Palette, horizontal lockup, favicon scale ladder, executive presentation sheet).

## Execution Directives
- Pass rendered stages to `artifacts/stageX.webp` via `ExecuteScript(..., outFile="artifacts/stageX.webp")`.
- Verify multi-scale favicon legibility from 16px to 256px before finalizing.
- Render final presentation board to `output.webp` and save full JavaScript to `artwork.js`.
